The program defines a structure named student containing the following members:
name – stores the student's name.
rollno – stores the student's roll number.
marks – stores the student's marks.
city – stores the student's city.
dream – stores the student's dream.
An array of structures, s[10], is used to store the details of 10 students.
The for loop is used to collect the details of each student using scanf(). After entering all the details, another for loop displays the information of all 10 students using printf().
